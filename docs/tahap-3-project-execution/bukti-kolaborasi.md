# Tahap 3 — Bukti Kolaborasi GitHub

[⬅️ Catatan Rapat](catatan-rapat.md) &nbsp;|&nbsp; [README ➡️](../../README.md)

---

Bukti kolaborasi diambil langsung dari GitHub, bukan ditulis ulang. Alur kerja mengikuti [docs/git-github.md](../git-github.md) dan README: tiap pekerjaan dikerjakan di branch sendiri, lalu digabung lewat *pull request* yang ditinjau anggota lain.

## 1. Aturan yang Dipakai

| Hal | Aturan |
| --- | --- |
| Nama branch | `kode-wbs/singkat`, contoh `5.2/kerangka-halaman`, `3.1/data-menu` |
| Pesan commit | Kalimat perintah yang jelas, contoh `Tambah filter kategori menu` |
| Pull request | Judul memuat kode WBS; minimal satu anggota lain meninjau sebelum digabung ke `main` |
| Branch `main` | Hanya menerima hasil pull request |

## 2. Daftar Bukti (diisi dari GitHub)

| Bukti | Cara mengambil | Tautan/gambar |
| --- | --- | --- |
| Daftar anggota/collaborator | Settings → Collaborators | *isi: tangkapan layar di `assets/bukti/collaborators.png`* |
| Riwayat commit per anggota | Tab Insights → Contributors, atau tab Commits | *isi: tangkapan layar* |
| Pull request yang sudah ditinjau | Tab Pull requests → Closed | *isi: tautan PR* |
| Grafik aktivitas | Insights → Pulse | *isi: tangkapan layar* |
